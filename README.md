# 云宿充 · 充电运营管理平台交互原型

一期后台交互原型采用原生 HTML、CSS 和 JavaScript，由标准 ESM Worker 输出页面。

## 当前功能范围

- 运营管理：场站管理、收费方案、预约调价及场站停车减免说明。
- 平台对接：道闸管理；停车场系统接入参数独立维护，场站只选择应用配置。
- 设备管理：充电桩、充电枪、充电桩日志。
- 营销活动：活动管理、会员卡管理、充值套餐管理；优惠券能力统一归入活动管理。
- 订单管理：充电订单、充值订单、会员卡订单、充电投诉。
- 用户与企业：用户档案、用户分组、免费用户、企业预付账户、车辆和财务。
- 财务管理：收支明细、对账报表、退款审批和发票预留入口。

## 本次更新

- 删除独立“优惠券管理”菜单及页面，活动管理统一配置领券二维码、兑换码 / 卡密、使用规则说明、单次优惠上限、每人领取上限及小程序展示方式。
- 活动管理筛选项移除“参与场站”；小程序展示方式仅支持首页弹窗、首页 Banner、领券中心。
- 单次优惠上限和每人领取上限均为非必填；未配置时分别按“不限制且小程序不展示”和“不限制领取数量”处理。
- 活动审批设置仅在“运营商维度 + 指定运营商”时展示，审批任务仅对所选运营商可见。
- 新增一级菜单“平台对接”，道闸管理作为其二级菜单；道闸管理移除顶部统计、配置编号及厂商 / 接入方式筛选。
- 道闸接入字段调整为停车场系统、APP ID、APP Secret、停车场 ID、停车场名称、交流桩满足减免时长、直流桩满足减免时长。
- 会员卡支持最高每月可省金额和优惠金额承担方配置。
- 会员卡管理的持卡会员、会员站支持查询。
- 订单管理新增会员卡订单；充电投诉、充值订单、会员卡订单退款统一使用右侧抽屉。
