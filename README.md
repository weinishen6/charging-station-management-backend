# 云宿充 · 充电运营管理平台交互原型

一期前端交互原型采用原生 HTML、CSS 和 JavaScript，由标准 ESM Worker 输出页面。

## 功能范围

- 运营管理：场站管理、收费管理（收费方案、预约调价）。
- 设备管理：充电桩、充电枪、充电桩日志。
- 营销活动：活动投放、优惠券、会员卡、充值套餐管理。
- 订单管理：充电订单、充值订单、充电投诉。
- 用户管理：用户档案、用户分组、免费用户。
- 企业管理：预付账户、订单、退款、车辆和财务。
- 财务管理：收支明细、三类对账报表、退款审批、发票预留入口。

场站支持卡片与列表切换：顶部使用运行状态、通讯状态环形图和设备状态分段图进行紧凑统计；卡片采用四列紧凑布局，列表支持字段显隐和拖动排序，并展示超快充、快充、慢充、当前时段、当前价格及分账比例。新增、编辑和详情共用完整字段模型，地址支持“省 / 市 / 区 + 详细地址”与原型地图双向填充，选择运营商后自动回显分佣比例；充电桩采用可搜索、按状态筛选和多选的设备选择器。

收费管理将收费方案与预约调价整合在同一页面。同一尖、峰、平、谷类别可建立多条不同价格配置，24 小时时段绑定到具体价格配置；预约调价先选择运营商，再筛选、多选应用场站，新增、编辑、详情和列表均展示一致的信息。营销活动提供快捷模板，个人和企业车辆支持 VIN 与即插即充。

充值订单将充值本金与营销赠送金分账展示，并独立记录使用状态、退款状态、银联商户号、银联交易流水、充值及退款时间。未使用订单可退全部本金，部分使用订单仅退剩余本金，本金用完后不可退款；退款完成后同步回收未使用赠送金。充值套餐支持维护充值金额、赠送金额、有效期和启用状态，并统计累计充值金额；长期有效套餐不展示生效、失效日期。平台统一在编辑界面维护启用状态，列表与详情仅作状态展示。
