# 云宿充 · 充电运营管理平台交互原型

一期后台交互原型采用原生 HTML、CSS 和 JavaScript，由标准 ESM Worker 输出页面。

## 当前功能范围

- 运营管理：场站管理、收费方案、预约调价、道闸系统接入及场站停车减免说明。
- 设备管理：充电桩、充电枪、充电桩日志。
- 营销活动：活动管理、优惠券管理、会员卡管理、充值套餐管理。
- 订单管理：充电订单、充值订单、会员卡订单、充电投诉。
- 用户与企业：用户档案、用户分组、免费用户、企业预付账户、车辆和财务。
- 财务管理：收支明细、对账报表、退款审批和发票预留入口。

## 本次更新

- 优惠券支持扫码领券、领券二维码查看与下载。
- 优惠券支持兑换码 / 卡密批次管理、兑换状态查看和未兑换卡密导出。
- 优惠券支持每人领取上限、单次优惠上限、使用规则说明、小程序展示方式及实时预览。
- 活动审批设置仅在“运营商维度 + 指定运营商”时展示，审批任务仅对所选运营商可见。
- 会员卡支持最高每月可省金额和优惠金额承担方配置。
- 会员卡管理的持卡会员、会员站支持查询。
- 订单管理新增会员卡订单；充电投诉、充值订单、会员卡订单退款统一使用右侧抽屉。
- 场站选择已接入的道闸配置，第三方道闸参数在独立管理模块维护。
